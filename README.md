# STM32 Edge AI: Salt vs. Sugar Spectral Classifier

This repository contains the firmware for an embedded machine learning (TinyML) project that distinguishes between salt and sugar using light spectrum analysis. It runs on an STM32 microcontroller, interfaces with an **AS7341 11-channel spectral color sensor**, and uses a neural network deployed via **STMicroelectronics X-CUBE-AI** for real-time edge inference.

## 🚀 Features

* **Real-time Classification:** Distinguishes between salt and sugar based on their spectral signatures.
* **Sensor Integration:** Custom I2C driver for the AS7341 sensor, including SMUX configuration to read 8 optical channels sequentially.
* **Edge AI Inference:** Utilizes a pre-trained neural network optimized for microcontrollers via X-CUBE-AI.
* **On-Device Preprocessing:** Implements a `StandardScaler` (Z-score normalization) in C using mean and standard deviation parameters extracted from the training dataset.
* **Serial Debugging:** Formatted UART output displaying raw sensor data, raw AI prediction values, and human-readable confidence percentages.

## 🛠 Hardware Requirements

* **Microcontroller:** STM32 Development Board (e.g., STM32 Nucleo with Cortex-M4/M7, running at 180MHz).
* **Sensor:** AS7341 11-Channel Spectral Color Sensor.
* **Connections:**
* `I2C1` (SDA/SCL) connected to the AS7341.
* `USART2` configured for serial output over USB (115200 baud).



## 🧰 Software & Tools

* **STM32CubeIDE:** Primary development environment.
* **STM32CubeMX:** Peripheral configuration (I2C, UART, System Clock).
* **X-CUBE-AI:** STMicroelectronics expansion package to convert the pre-trained neural network (e.g., TensorFlow/Keras) into optimized C code.

## 🧠 How It Works

1. **Data Acquisition:** The AS7341 sensor is initialized, and its internal multiplexer (SMUX) is toggled to capture 8 distinct spectral bands (F1-F8).
2. **Normalization:** The raw 16-bit sensor readings are normalized using hardcoded `SCALER_MEAN` and `SCALER_STD` values to match the feature scale expected by the neural network.
3. **Inference:** The normalized floating-point array is fed into the X-CUBE-AI network.
4. **Classification:** The network outputs a single floating-point value (sigmoid activation).
* `Output >= 0.5`: Classified as **SUGAR**.
* `Output < 0.5`: Classified as **SALT**.


5. **Output:** Results are printed via `printf` to the Serial Monitor every 400ms.

## 💻 Setup and Usage

1. Clone this repository and import the project into **STM32CubeIDE**.
2. Ensure your AS7341 sensor is connected to the I2C1 pins of your STM32 board.
3. Compile and flash the firmware to your microcontroller.
4. Open a Serial Terminal (e.g., PuTTY, TeraTerm, or the built-in IDE terminal) and connect to the board's virtual COM port.
5. **Serial Configuration:**
* Baud Rate: `115200`
* Data bits: `8`
* Parity: `None`
* Stop bits: `1`
